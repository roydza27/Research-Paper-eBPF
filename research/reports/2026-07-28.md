## Important Findings & Emerging Trends
* **Hardware-Assisted Isolation is the Trend:** While early work (like SandBPF in 2023) focused on SFI (Software Fault Isolation) using masking, recent SOSP/OSDI/USENIX papers (like HIVE and SafeBPF in 2024) use ARM AArch64 hardware features (MTE and PAC) to achieve low overhead (3-4%) and strict memory safety.
* **Verifier Fragility:** Hao Sun's work shows that fuzzing and state embedding reveal critical verifier arithmetic bugs frequently. Therefore, relying only on compile-time verification is insufficient for unprivileged cloud tenants.

## New Implementations & GitHub Leads
* **eBPF-PATROL:** Nepalese team created an active runtime policy agent.
* **bpfbox/BPFContain:** William Findlay's repo focuses on process confinement via BPFLSM hooks.
