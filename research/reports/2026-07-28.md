## Technical Findings
* **The Namespace Deficit:** Unlike process control groups, eBPF lacks native namespace boundaries. In multitenant clouds, containers sharing a kernel can access host BPF maps unless patched via LSM hooks.
* **Static Verification is Fragile:** Fuzzing tools like State Embedding show consistent logic bugs inside the verifier's mathematical abstract domain bounds tracker, implying that runtime sandboxing (using SFI) is crucial.
* **Offensive eBPF Escape:** USENIX '23 research proves that sidecars with general monitoring capability can be abused to perform container breakouts.
